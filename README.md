# balayokesh_portfolio

A scroll-driven, cinematic portfolio for Balayokesh, UX/UI Designer.

You start at a closed door. Step in, and the camera moves through the room: the neon sign, the mirror,
the desk with its notes, the resume frame, a monitor showing projects and experience, and finally the
bean bag where you can get in touch.

## Run it

It is a single static page, `index.html`, with its pictures and videos in `assets/`.
Serve the folder with any static server, for example:

```bash
npx serve .
```

It also works on GitHub Pages: set Pages to deploy from the `main` branch, root folder.

## Built with

- HTML, CSS and JavaScript
- [GSAP](https://gsap.com/) for the scroll timeline
- Google Fonts: Archivo, Bebas Neue, Caveat
